# Starbucks Sales & Beverage Analytics Dashboard

## 📊 Project Overview

This project is an interactive **Starbucks Beverage Analytics Dashboard** built in **Microsoft Power BI**. The dashboard analyzes beverage-level nutritional data and provides a visual view of beverage categories, calories, sugar, protein, and beverage selection.

The goal is to turn raw Starbucks beverage data into an easy-to-use dashboard that helps users explore nutritional characteristics and compare beverage categories.

## 🎯 Objectives

- Analyze Starbucks beverage and nutritional data.
- Compare beverage categories using key nutritional metrics.
- Identify differences in calories, sugar, and protein across beverage categories.
- Provide interactive filtering for individual beverages.
- Present important KPIs in a simple and visually appealing Power BI dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query** – Data preparation and transformation
- **DAX** – Measures and KPI calculations
- **Data Visualization** – Cards, area charts, donut charts, column charts, and bar charts

## 📁 Dataset

The dashboard is based on Starbucks beverage data containing nutritional attributes such as:

- Beverage
- Beverage Category
- Calories
- Sugar
- Protein
- Other beverage-related nutritional fields

> **Note:** The `.pbix` file contains the Power BI data model, calculations, visualizations, and dashboard layout.

## 📈 Dashboard Features

### KPI Cards
The dashboard highlights key metrics including:

- Total Beverage
- Average Sugar
- Average Calories
- Average Protein

### Visual Analysis

- **Average Calories by Beverage Category** – compares calorie levels across categories.
- **Beverage Category Distribution** – shows the contribution of beverage categories.
- **Average Protein by Beverage Category** – compares protein content across categories.
- **Average Sugar by Beverage Category** – highlights differences in sugar content.
- **Beverage Filter** – allows users to select and analyze individual beverages.
- **Protein Range Filter** – allows users to interactively filter the analysis based on protein content.

## 🔍 Key Analysis Areas

The dashboard can be used to explore questions such as:

1. Which beverage categories have higher average calories?
2. Which categories have higher average sugar content?
3. How does protein content vary between beverage categories?
4. How does an individual beverage compare with other beverages?
5. How do nutritional metrics change when different filters are applied?

## 💡 Insights

The dashboard provides a visual way to identify nutritional patterns across Starbucks beverage categories. Users can compare categories and drill into individual beverages using the interactive filters.

The analysis is intended for **exploratory and educational purposes** rather than nutritional or medical advice.
